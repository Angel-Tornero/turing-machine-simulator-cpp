# Turing Machine Simulator - C++ (University Project)

## 📝 Description

This project implements a Turing Machine simulator in C++. It allows users to define Turing Machines through configuration files and test whether specific strings are accepted by the machine.

The simulator was developed as part of a university course called *Computational Complexity*.

---

### 🔧 How to Run

To execute the simulator, use the following format:

```ssh
./main [machine_definition_file] [input_strings_file (optional)]
```

Example:

```ssh
./main machines/mt-1.tm data/input_strings.txt
```

- `machines/example.tm`: File containing the Turing Machine definition.
- `data/input_strings.txt`: File with input strings to be tested against the Turing Machine (optional).
